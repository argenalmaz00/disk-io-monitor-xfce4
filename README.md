# Disk I/O Monitor — xfce4-genmon-plugin

Монитор дискового ввода/вывода для XFCE Panel через Generic Monitor (genmon).

## 📋 Описание

Плагин отображает вертикальные прогресс-бары для каждого физического диска в системе:
- **Левый бар** (зелёный) — загрузка при чтении (%)
- **Правый бар** (красный) — загрузка при записи (%)

Формат отображения на панели:
```
sda || sdb || sdc ||
```
Где `sda`, `sdb`, `sdc` — имена дисков, а `||` — два вертикальных бара (чтение и запись).

## ✨ Возможности

- ✅ **Автоматическое сохранение** — все настройки применяются сразу, без кнопки "Сохранить"
- ✅ **Отображение скорости** — в tooltip показывается скорость чтения/записи (TB/s, GB/s, MB/s, KB/s)
- ✅ **Настройка прозрачности фона** — ползунок 0-100% для видимости фона прогресс-баров
- ✅ **Серый фон баров** — улучшенная видимость фона (цвет #404047)
- ✅ **Total % нагрузки** — общий процент загрузки диска (busy time)
- ✅ **Автономная работа** — плагин работает сразу после установки, не требует указания пути к файлу

## 📦 Установка

### Быстрая установка (рекомендуется)

```bash
./install.sh
```

Скрипт автоматически:
- Установит зависимости (Python3, pycairo, python3-gi, xfce4-genmon-plugin)
- Скопирует скрипты в `/usr/local/bin/`
- Протестирует работу
- Покажет инструкцию по добавлению на панель

### Ручная установка

1. **Скопируйте файлы в систему**

```bash
sudo cp disk-io-monitor /usr/local/bin/
sudo cp disk-io-monitor-settings /usr/local/bin/
sudo chmod +x /usr/local/bin/disk-io-monitor
sudo chmod +x /usr/local/bin/disk-io-monitor-settings
```

2. **Добавьте в панель XFCE**

1. Правой кнопкой на панели → **Panel** → **Add New Items...**
2. Найдите **Generic Monitor** и добавьте его
3. Переместите его на нужное место в панели
4. Правой кнопкой на новом виджете → **Properties**

3. **Настройте Generic Monitor**

В свойствах укажите:

| Параметр | Значение |
|----------|----------|
| **Command** | `disk-io-monitor` |
| **Period** | `1` (секунда) |
| **Label** | (оставьте пустым) |
| **Show Label** | ❌ снять галочку |

4. **Готово!**

Плагин начнёт отображать загрузку дисков **сразу после добавления**. Не требуется дополнительная настройка — мониторинг работает автономно.

## ⚙️ Настройки

Кликните по значку ⚙ на панели (или выполните команду `disk-io-monitor-settings`) для открытия окна настроек.

### Доступные параметры:

| Параметр | Описание |
|----------|----------|
| **Цвет Read** | Цвет бара чтения (по умолчанию #44ee77 — зелёный) |
| **Цвет Write** | Цвет бара записи (по умолчанию #ee3333 — красный) |
| **Толщина (px)** | Ширина одного бара в пикселях (4-50) |
| **Высота (px)** | Высота баров в пикселях (10-120) |
| **Зазор (px)** | Расстояние между барами (1-20) |
| **Прозрачность (%)** | Прозрачность серого фона баров (0-100%) |
| **Показывать % чтения** | Отображать ли левый бар (чтение) |
| **Показывать % записи** | Отображать ли правый бар (запись) |

Все настройки применяются **мгновенно** и сохраняются в файл конфигурации.

## 📁 Файлы

| Файл | Назначение |
|------|------------|
| `/usr/local/bin/disk-io-monitor` | Основной скрипт мониторинга |

## 🛠 Требования

- Python 3.6+
- PyGObject (GTK3)
- PyCairo (для отрисовки баров)
- XFCE4 Panel с плагином genmon

### Установка зависимостей (Debian/Ubuntu):

```bash
sudo apt install python3-gi python3-cairo xfce4-genmon-plugin
```

### Установка зависимостей (Fedora/RHEL):

```bash
sudo dnf install python3-gobject python3-cairo xfce4-genmon-plugin
```

## 🎯 Как это работает

1. Скрипт сканирует `/dev/disk/by-id/` и `/dev/disk/by-path/` для поиска физических дисков
2. Читает `/proc/diskstats` для получения статистики I/O
3. Вычисляет процент загрузки (busy time) на основе времени выполнения операций
4. Вычисляет скорость чтения/записи в байтах в секунду
5. Рисует PNG-изображение с вертикальными барами через Cairo
6. Возвращает изображение в genmon для отображения в панели

## 📝 Примечания

- **Первый запуск**: При первом запуске скорость может отображаться неверно (нет предыдущих данных). Через 1-2 секунды всё нормализуется.
- **NVMe диски**: Отображаются как `nvme0n1`, `nvme1n1` и т.д.
- **Партиции игнорируются**: Показываются только физические диски, не партиции.
- **Частота обновления**: Рекомендуется устанавливать Period = 1 сек для баланса между точностью и нагрузкой на CPU.

## 🐛 Устранение проблем

### Не видно фон прогресс-баров
- Увеличьте значение "Прозрачность (%)" в настройках (рекомендуется 70-100%)
- Фон теперь серый (#404047) для лучшей видимости

### Не отображаются диски
- Проверьте права доступа к `/proc/diskstats`
- Убедитесь, что диски подключены и видны в системе

### Ошибка "ERR: ..."
- Установите PyCairo: `sudo apt install python3-cairo`
- Проверьте, что файл `/tmp/disk_io_monitor_bars.png` может быть создан
