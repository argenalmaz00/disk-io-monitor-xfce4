# Disk I/O Monitor

Монитор дискового ввода/вывода для XFCE4 Panel (GenMon plugin).  
Показывает вертикальные прогресс-бары для каждого диска с настраиваемыми параметрами.

## 📋 Возможности

- **Вертикальные бары** — два бара на каждый диск:
  - Левый = Read (чтение)
  - Правый = Write (запись)
- **Формат отображения**: `sda || sdb || sdc ||`
- **Настраиваемые цвета** — отдельные цвета для чтения и записи
- **Прозрачность фона** — ползунок регулировки прозрачности (0-100%)
- **Отображение %** — кнопки включения/отключения процентов чтения и записи
- **Авто-сохранение** — все настройки применяются сразу, без кнопки "Сохранить"
- **Размеры баров** — настройка толщины, высоты и зазора между барами

## 🚀 Установка

```bash
./install.sh
```

Скрипт установки:
- Копирует файлы в `/usr/local/bin`
- Создаёт конфигурационную директорию `~/.config/disk-io-monitor`

## ⚙️ Настройка

### Запуск настроек

Кликните на значок ⚙ в панели или выполните команду:

```bash
disk-io-monitor-settings
```

### Параметры настроек

| Параметр | Описание |
|----------|----------|
| **Цвет Read** | Цвет бара чтения (по умолчанию: #44ee77) |
| **Цвет Write** | Цвет бара записи (по умолчанию: #ee3333) |
| **Толщина (px)** | Ширина одного бара в пикселях (4-50) |
| **Высота (px)** | Высота баров в пикселях (10-120) |
| **Зазор (px)** | Расстояние между барами (1-20) |
| **Прозрачность (%)** | Прозрачность фона прогресс-бара (0-100) |
| **Показывать % чтения** | Включить/отключить отображение бара чтения |
| **Показывать % записи** | Включить/отключить отображение бара записи |

### Добавление в панель XFCE

1. ПКМ на панели → **Панель** → **Добавить новые элементы**
2. Найдите **Generic Monitor**
3. Перетащите его на панель
4. ПКМ на Generic Monitor → **Свойства**
5. В поле **Command** укажите: `disk-io-monitor`
6. Установите **Period** на 1 секунду (рекомендуется)
7. Клик по значку ⚙ откроет окно настроек

## 🗂 Конфигурация

Конфигурационный файл сохраняется в:
```
~/.config/disk-io-monitor/config.json
```

Пример конфигурации:
```json
{
  "read_color": "#44ee77",
  "write_color": "#ee3333",
  "bar_width": 10,
  "bar_height": 28,
  "bar_gap": 3,
  "bg_opacity": 85,
  "show_read_pct": true,
  "show_write_pct": true
}
```

## 🔧 Технические детали

### Определение дисков
Скрипт автоматически определяет физические диски через:
1. `/dev/disk/by-id/` (приоритет)
2. `/dev/disk/by-path/`
3. `/proc/diskstats` (резервный вариант)

Фильтруются:
- Партиции (например, `sda1`, `nvme0n1p1`)
- Loop устройства
- RAM диски
- CD/DVD приводы

### Расчёт загрузки
Процент загрузки вычисляется из `/proc/diskstats`:
- **Read busy** = время чтения / интервал × 100%
- **Write busy** = время записи / интервал × 100%


## 📸 Пример использования

```
sda || sdb || sdc ||
██    ██    ░░    
██    ░░    ░░    
```

- `█` = активный бар (зелёный = чтение, красный = запись)
- `░` = фон бара (с настраиваемой прозрачностью)
